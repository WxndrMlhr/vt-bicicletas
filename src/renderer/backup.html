Backup

Cópias de segurança de tudo: produtos, pedidos, clientes, estoque e contas.

O sistema guarda uma cópia toda vez que você abre o app, uma por dia, mantendo os últimos 30 dias. Se algo der errado — um reajuste aplicado por engano, um arquivo corrompido — dá para voltar para qualquer uma dessas cópias.

As cópias ficam no mesmo computador. Para se proteger de um HD queimado, copie a pasta para um pen drive de vez em quando.

Onde ficam os dados

Todo o sistema vive num arquivo só. É esse arquivo que você copia para o pen drive.
